## 📝 To-Do List Application

A beginner-friendly command-line application built with Python. The application allows users to add tasks, view their task list, and manage daily tasks through a simple menu-driven interface.

## Features

- Add new tasks.
- View all saved tasks.
- Display tasks with automatic numbering.
- Handle invalid menu choices.
- Simple and user-friendly interface.
- Exit the application safely.

## Technologies & Concepts Used

- Python
- Lists
- Loops
- Conditional Statements
- Functions (if added later)
- User Input Handling
- Input Validation
- enumerate()
